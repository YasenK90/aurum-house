# Aurum House — Hotel Portfolio Demo

A boutique-hotel website designed as a portfolio piece: editorial typography, restrained palette, real-feeling copy, responsive layout, and a working booking-request modal.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

The demo uses remote photography from Unsplash for presentation purposes. Replace image URLs and booking contact details before using commercially.
